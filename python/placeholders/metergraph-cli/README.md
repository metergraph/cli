# metergraph-cli

This name is held by Metergraph so that it cannot be registered by anyone
else. The package contains no functionality.

The Metergraph CLI is published on npm, not PyPI. Run it with:

    npx metergraph-cli@next

To install the Metergraph agent skill from Python, use metergraph-skills.

The Python SDK is published as `metergraph`. Source:
https://github.com/metergraph/cli
